# CV interactif — Théophile Hennuyer · V2

Cette version est basée sur le contenu du CV PDF fourni.

## Contenu
- `index.html` : site complet
- `style.css` : design responsive
- `script.js` : animations, barre de progression, compteurs et mode sombre
- `photo-theophile.png` : portrait extrait du CV
- `CV-Theophile-Hennuyer-2026.pdf` : CV PDF actuel pour le bouton de téléchargement

## À faire avant publication
1. Remplacer le texte du bloc LinkedIn dans `index.html` par ton vrai lien LinkedIn.
2. Vérifier les informations et les dates.
3. Si tu veux, remplacer les niveaux de compétences indicatifs par des niveaux que tu assumes réellement.

## Publier gratuitement avec GitHub Pages
1. Va sur GitHub et crée un repository public nommé `cv-interactif`.
2. Ajoute tous les fichiers de ce dossier à la racine du repository.
3. Ouvre `Settings` → `Pages`.
4. Dans `Build and deployment`, sélectionne `Deploy from a branch`.
5. Choisis `main` puis `/ (root)` et sauvegarde.
6. Après quelques instants, GitHub affichera l'adresse de ton site, de la forme :
   `https://TON-PSEUDO.github.io/cv-interactif/`

Tu pourras ensuite mettre ce lien dans tes candidatures et sur LinkedIn.
